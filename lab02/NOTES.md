## Git: рабочая папка, индекс и коммит
Рабочая папка

Рабочая папка — это файлы проекта на моём компьютере, которые я могу изменять. Изменения сначала появляются именно здесь.

## Индекс

Индекс — это область, куда я помещаю изменения, подготовленные для следующего коммита. Команда `
git add` добавляет изменения из рабочей папки в индекс.

## Коммит

Коммит — это сохранённое в истории Git состояние подготовленных изменений. Он позволяет сохранить результат работы и вернуться к нему в будущем.


## Git и GitHub

Git — это система контроля версий, которая хранит историю изменений проекта в репозитории на компьютере.

GitHub — это онлайн-сервис для хранения удалённых Git-репозиториев и обмена изменениями между компьютерами и пользователями.

Команда `git commit` сохраняет изменения в локальной истории Git. Команда `git push` отправляет локальные коммиты в удалённый репозиторий на GitHub.

## git diff и git diff --staged

Команда `git diff` показывает изменения между рабочей папкой и последним коммитом. Она показывает изменения, которые ещё не добавлены в индекс.

Команда `git diff --staged` показывает изменения между индексом и последним коммитом. Она показывает изменения, которые уже добавлены командой `git add` и подготовлены для следующего коммита.

## Использованные команды

`git status` показывает текущее состояние рабочей папки и индекса: какие файлы изменены, какие изменения подготовлены для коммита и какие файлы ещё не отслеживаются.

`git diff` показывает изменения в рабочей папке, которые ещё не добавлены в индекс.

`git diff --staged` показывает изменения, добавленные в индекс и подготовленные для следующего коммита.
