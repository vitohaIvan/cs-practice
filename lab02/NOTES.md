Git: рабочая папка, индекс и коммит
Рабочая папка

Рабочая папка — это файлы проекта на моём компьютере, которые я могу изменять. Изменения сначала появляются именно здесь.

Индекс

Индекс — это область, куда я помещаю изменения, подготовленные для следующего коммита. Команда git add добавляет изменения из рабочей папки в индекс.

Коммит

Коммит — это сохранённое в истории Git состояние подготовленных изменений. Он позволяет сохранить результат работы и вернуться к нему в будущем.
